## 🔑 Part D: Open-Ended Feedback — Top Themes

### 1️⃣ Performance — Most Complained Issue
- **"ประมวลผลช้า"** (Processing is slow) — mentioned by 10+ users
- No progress indicator during processing
- No estimated time remaining

### 2️⃣ UX / Interface Issues
- Preview is vertical → hard to read, want horizontal/landscape layout
- Font too large in preview before export
- Need prompt templates for beginners who don't know what to type
- Forgot password feature missing
- Want output format choice (docx, xls, jpg, slide)
- Want pre-built menus: strategic plan, action plan, project proposal

### 3️⃣ Data & Citation Quality
- 403 Forbidden errors: ThaiJO timeout, Diabetes DB forbidden
- Limited data sources — want PubMed, Scopus, Web of Science
- Data only shows province level — need district/sub-district level
- Some wrong data returned (diabetes query → TB result)
- Broken citation links (some URLs return no data)

### 4️⃣ Report Structure Gaps
- Executive Summary (บทสรุปผู้บริหาร) — most requested
- SWOT Analysis — frequently requested
- Six Building Blocks of Health System framework
- PDCA analysis
- Sub-district/village level recommendations
- Budget allocation section

### 5️⃣ Data Gaps by Domain

**Road Accidents:**
- Village-level risk point data
- Police department data (cross-reference with hospital data)
- Road accident time patterns, frequent routes
- Environmental factors (lighting, signs, curves)

**Mental Health:**
- Hotline statistics
- Medication prescription data
- Suicide rate by gender, age, method, motivation
- Drug abuse/addiction data

**NCDs (Non-Communicable Diseases):**
- HDC (Health Data Center) database
- NHES survey (ครั้งที่ 1–7)
- School nutrition/dietary behavior
- Disease-specific diet recommendations

**Other Requested Areas:**
- Communicable disease control (โรคติดต่อ)
- Elderly care planning (ผู้สูงอายุ)
- Cancer (โรคมะเร็ง)
- อสม. program data
- HR/workforce planning (กรอบอัตรากำลัง)
- Legal/regulatory framework (กฎหมายสาธารณสุข)
