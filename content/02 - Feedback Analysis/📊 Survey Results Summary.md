## 🔑 Part D: Open-Ended Feedback — Top Themes

### 1️⃣ Performance — Most Complained Issue
- **"ประมวลผลช้า"** (Processing is slow) — mentioned by 10+ users
- No progress indicator during processing
- No estimated time remaining

### 2️⃣ UX / Interface Issues
- Preview is vertical → hard to read, want horizontal/landscape layout
- Font too large in preview before export
- Need prompt templates for beginners who don't know what to type
- Forgot password feature missing
- Want output format choice (docx, xls, jpg, slide)
- Want pre-built menus: strategic plan, action plan, project proposal

### 3️⃣ Data & Citation Quality
- 403 Forbidden errors: ThaiJO timeout, Diabetes DB forbidden
- Limited data sources — want PubMed, Scopus, Web of Science
- Data only shows province level — need district/sub-district level
- Some wrong data returned (diabetes query → TB result)
- Broken citation links (some URLs return no data)

### 4️⃣ Report Structure Gaps
- Executive Summary (บทสรุปผู้บริหาร) — most requested
- SWOT Analysis — frequently requested
- Six Building Blocks of Health System framework
- PDCA analysis
- Sub-district/village level recommendations
- Budget allocation section

### 5️⃣ Data Gaps by Domain

**Road Accidents:**
- Village-level risk point data
- Police department data (cross-reference with hospital data)
- Road accident time patterns, frequent routes
- Environmental factors (lighting, signs, curves)

**Mental Health:**
- Hotline statistics
- Medication prescription data
- Suicide rate by gender, age, method, motivation
- Drug abuse/addiction data

**NCDs (Non-Communicable Diseases):**
- HDC (Health Data Center) database
- NHES survey (ครั้งที่ 1–7)
- School nutrition/dietary behavior
- Disease-specific diet recommendations

**Other Requested Areas:**
- Communicable disease control (โรคติดต่อ)
- Elderly care planning (ผู้สูงอายุ)
- Cancer (โรคมะเร็ง)
- อสม. program data
- HR/workforce planning (กรอบอัตรากำลัง)
- Legal/regulatory framework (กฎหมายสาธารณสุข)

## 🔑 รอบ 2 — Open-Ended Top Themes (ต่างจากรอบ 1)

> [!warning] ปัญหาเปลี่ยนชั้น: รอบ 1 = "ช้า/ใช้ยาก" → รอบ 2 = "ข้อมูลไม่นิ่ง/เชื่อไม่ได้"

### 1️⃣ ความเสถียร & ความแม่นของข้อมูล (ใหม่ — เด่นสุด)
- ผลลัพธ์ไม่นิ่ง — prompt เดียวกันได้ผลต่างกัน (nugrataeee) *(แนวทางแก้: ควรตั้งค่าพารามิเตอร์ของ AI (Temperature=0) เฉพาะส่วนดึงสถิติ)*
- ขอข้อมูลปี 2568 ได้ปี 2565–67 (nugrataeee) *(แนวทางแก้: ควรเพิ่มป้ายกำกับปีข้อมูล "Data Year Badge" บนรายงานให้เห็นชัดเจน)*
- ตัวแปรในการคำนวณคลาดเคลื่อน (paithulkhamsombat) *(แนวทางแก้: ควรมีการตรวจสอบสูตรและที่มาของตัวเลขสถิติ หรือเปิดให้ผู้ใช้อัปโหลดไฟล์เป้าหมาย KPI ได้เอง)*
- รายงานผลไม่ตรงคำสั่ง (saengpakman) *(แนวทางแก้: ระบบต้องถูกปรับจูนให้ทำตามคำสั่งเคร่งครัด และควรมีปุ่ม "ปรับแก้เฉพาะจุด (Partial Edit)")*

### 2️⃣ Citation หายไป (เสี่ยง regression จากรอบ 1)
- "ยังไม่พบการอ้างอิงแหล่งที่มา" (dr.weerapan.s) *(แนวทางแก้: ต้องแสดงแหล่งที่มาของข้อมูลทุกครั้ง หรือสร้างหน้าต่าง Preview Source Document ด้านข้างรายงาน)*

### 3️⃣ ความต้องการเชิงนโยบายเฉพาะเจาะจงขึ้น
- นำเข้านโยบายชาติ: ยุทธศาสตร์ 20 ปี, 30 บาทรักษาทุกที่ (dr.weerapan.s) *(แนวทางแก้: ควรทำระบบซิงค์ข้อมูลอัตโนมัติเชื่อมกับ MOPH API)*
- ป้อนกรอบ KPI ตัวเลขจริงเพื่อให้ AI วางแผนได้ (meltarchy) *(แนวทางแก้: เพื่อให้ AI นำตัวเลขไปคำนวณเป้าหมายความสำเร็จได้อย่างแม่นยำ)*
- เชื่อม MOPH Open Data (thanasith1986) *(แนวทางแก้: ข้อมูลที่คนป้อนเองอาจผิดพลาด ควรมีระบบตรวจสอบคุณภาพข้อมูลก่อนนำเข้า Data Validation & QA)*

### 4️⃣ วิเคราะห์ขั้นสูง
- พยากรณ์ + วิเคราะห์แนวโน้ม 5 ปี ไม่ใช่แค่สรุปอดีต (thanasith1986, meltarchy) *(แนวทางแก้: ควรใช้ Machine Learning แบบพื้นฐานมาวิเคราะห์เส้นแนวโน้มควบคู่กับ LLM)*
- สรุปข้อมูลเชิงเปรียบเทียบ (paithulkhamsombat) *(แนวทางแก้: เพื่อเปรียบเทียบข้อมูลของแต่ละอำเภอหรือปีให้เห็นความแตกต่างที่ชัดเจน)*

### 5️⃣ คำขอซ้ำจากรอบ 1
- Prompt Template พื้นฐาน (meltarchy) *(แนวทางแก้: ควรมีเมนูสำเร็จรูป หรือระบบ "คำถามแนะนำถัดไป" เพื่อลดความสับสนของผู้ใช้)*

### 6️⃣ ความต้องการใหม่เพิ่มเติม (พบจากบทวิเคราะห์ข้อมูล)
- เปิดให้แต่ละหน่วยงานอัปโหลดต้นแบบเอกสารของตนเองให้ AI เรียนรู้รูปแบบได้ (Custom Template RAG)
- ควรจัดทำ Focus Group แยกรายจังหวัด เพื่อเก็บความต้องการเชิงลึกให้แม่นยำกว่าการทำแบบสอบถามรวม (Provincial Focus Group)
