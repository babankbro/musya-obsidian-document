## 🔴 E1 — Determinism / Reproducibility
**แก้:** FR-R2-01, BUG-R2-01 · **ยก:** ฟอร์ม 3,5(+§5.4),7,9 · **กลุ่ม:** Phase 2-A

> [!danger] บั๊กร้ายสุดรอบ 2: prompt เดิม ผลต่างกัน → วัด Benchmark/Trust ไม่ได้เลย

### วิธีแก้ละเอียด
1. **ตั้ง `temperature=0` + `top_p=1` + `seed` คงที่** ที่ชั้นเรียก LLM ทุกจุด (ทั้ง Document RAG และ Database RAG)
2. **Pin เวอร์ชันโมเดล** (ระบุ model id ตายตัว ไม่ใช้ alias `latest`)
3. **Deterministic retrieval:** ล็อกลำดับ chunk ที่ดึง (sort by score แล้ว tie-break ด้วย doc_id) — กัน RAG คืน context สลับลำดับ
4. **Response cache:** key = hash(prompt + corpus_version + model_id) → prompt เดิม + คลังเดิม คืนผลเดิมทันที
5. **Corpus versioning:** ตีตราเวอร์ชันคลังข้อมูลทุกครั้งที่ ingest — ผลผูกกับเวอร์ชัน

### เกณฑ์ตรวจรับ
- [ ] รัน prompt ชุดทดสอบ 20 ข้อ × 3 ครั้ง → ผลเหมือนกัน 100% (diff = 0)
- [ ] cache hit คืนผลใน < 1s

## 🔴 E2 — Retrieval ตรงปี + Citation
**แก้:** FR-R2-02, FR-R2-05, BUG-R2-02, BUG-R2-05, BUG-004 · **ยก:** ฟอร์ม 3,5 §5.4,6,7 · **กลุ่ม:** Phase 2-A

> [!warning] ขอข้อมูลปี 2568 ได้ 2565–67 + รอบ 2 ไม่เห็น citation เลย (เสี่ยง regression)

### วิธีแก้ละเอียด
1. **Year-as-filter ไม่ใช่ keyword:** แยกปีออกจาก query เป็น metadata filter `WHERE year = :requested` — ไม่ปล่อยให้ semantic search เดาปี
2. **No silent fallback:** ถ้าไม่มีข้อมูลปีที่ขอ → แจ้งชัด "ไม่พบข้อมูลปี 2568 — ข้อมูลล่าสุดคือ 2567 ต้องการใช้แทนหรือไม่?" ห้ามสลับปีเงียบ ๆ
3. **Citation pipeline restore:** ตรวจว่าฟีเจอร์ citation หายหลัง refactor หรือไม่ (BUG-R2-05) — bind ทุกย่อหน้ากับ `{source, year, url}`
4. **Citation validation:** ping URL ตอน generate; ลิงก์ตาย → mark + หา mirror (แก้ BUG-004 จากรอบ 1)
5. **แสดง citation inline** ใต้ทุกตัวเลข/ข้อความอ้างอิง ไม่ใช่รวมท้ายเอกสาร

### เกณฑ์ตรวจรับ
- [ ] ขอปี X → ได้ปี X หรือข้อความแจ้งชัด (ทดสอบ 10 ปี/โดเมน)
- [ ] ทุกย่อหน้ามีแหล่ง + ปี, ลิงก์เปิดได้จริง 100%

## 🔴 E3 — Calculation Accuracy
**แก้:** FR-R2-05, BUG-R2-04, BUG-012 · **ยก:** ฟอร์ม 6,7 (+5 §5.4) · **กลุ่ม:** Phase 2-A

> [!warning] ตัวแปรในการคำนวณคลาดเคลื่อน + หน่วยนับปนกัน (ราย vs อัตรา/ประชากร)

### วิธีแก้ละเอียด
1. **ย้ายการคำนวณออกจาก LLM:** ใช้ tool/function call คำนวณด้วยโค้ด (Python) แทนให้โมเดลคิดเลขเอง — โมเดลแค่เลือกสูตร
2. **Unit registry:** กำหนดหน่วยมาตรฐานต่อ metric (เช่น "อัตราป่วยต่อแสนประชากร") + แปลงหน่วยอัตโนมัติก่อนคำนวณ (แก้ BUG-012)

4. **แสดงที่มาตัวเลข:** ทุกผลคำนวณโชว์ "ตัวตั้ง ÷ ตัวหาร × ฐาน" ให้ตรวจย้อนได้

### เกณฑ์ตรวจรับ
- [ ] unit-test สูตรครบทุกตัว ผ่าน 100%
- [ ] เทียบผล 10 เคสกับการคำนวณมือ → ตรงทุกเคส

## 🟡 E4 — Instruction-Following
**แก้:** BUG-R2-03 · **ยก:** ฟอร์ม 4,6,10 · **กลุ่ม:** Phase 2-A

> [!note] รายงานผลไม่ตรงคำสั่ง → เพิ่ม Frustration (TLX) + จุดสะดุด (Think-Aloud)

### วิธีแก้ละเอียด
1. **Structured intent parsing:** แยกคำสั่งผู้ใช้เป็น slots (โดเมน/พื้นที่/ปี/รูปแบบผลลัพธ์) ก่อน generate
2. **Plan-then-execute:** ให้ AI สรุป "เข้าใจว่าจะทำ X, Y, Z" ให้ผู้ใช้ยืนยันก่อนรันงานยาว
3. **Output contract:** กำหนด schema ผลลัพธ์ตามที่ขอ (ถ้าขอตาราง → ต้องได้ตาราง) + ตรวจ post-generation
4. **Self-check:** หลัง generate เทียบผลกับ slots ที่ parse ได้ ถ้าไม่ครบ → regenerate ส่วนที่ขาด

### เกณฑ์ตรวจรับ
- [ ] ชุดคำสั่งทดสอบ 15 ข้อ → ผลตรง intent ≥ 90%
