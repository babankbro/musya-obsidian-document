## 3. เปรียบเทียบคะแนน 2 รอบ

| มิติ          | รอบ 1 (n=24) | รอบ 2 (n=6) | Δ     | การตีความ                       |
| ------------- | ------------ | ----------- | ----- | ------------------------------- |
| SUS           | 57.9 ❌       | 55.4 ❌      | −2.5  | ทรงตัว — แต่กลุ่มคนละกลุ่ม      |
| AI Trust      | 3.56 🟡      | 3.23 🟡     | −0.33 | ลด — มีสาเหตุรากชัด (ผลไม่นิ่ง) |
| Policy Impact | 3.56 🟡      | 3.87 🟢     | +0.31 | เพิ่ม — ผู้บริหารเห็นคุณค่าชัด  |
|               |              |             |       |                                 |
|               |              |             |       |                                 |

> [!tip] หลักฐานไขว้ (Triangulation)
> ตัวเลขเชิงปริมาณ (Trust ลด) สอดคล้องกับ feedback เชิงคุณภาพ (prompt เดียวกันได้ผลต่างกัน) — ทำให้ข้อสรุปน่าเชื่อถือแม้ n เล็ก

## 4. การเปลี่ยนชั้นของปัญหา (Problem Shift)

```
รอบ 1: "ระบบช้า ใช้ยาก"          → แก้ UX/Performance ✅ สำเร็จ
รอบ 2: "ข้อมูลไม่นิ่ง เชื่อไม่ได้"   → ต้องแก้ Data Quality & Trust ⬅️ โจทย์ใหม่
```

| มิติ     | รอบ 1 (ปัญหาผิว)               | รอบ 2 (ปัญหาลึก)                                  |
| -------- | ------------------------------ | ------------------------------------------------- |
| เทคนิค   | ช้า, 403 Forbidden, UI แนวตั้ง | ผลไม่นิ่ง, ตัวแปรคำนวณคลาดเคลื่อน, ข้อมูลไม่ทันปี |
| ข้อมูล   | ลงลึกระดับตำบล/หมู่บ้าน        | นโยบายชาติ + KPI ตัวเลขจริง                       |
| ฟีเจอร์  | สรุปพื้นฐาน + รูปแบบรายงาน     | พยากรณ์ + วิเคราะห์แนวโน้ม 5 ปี                   |
| Citation | ลิงก์เสีย                      | "หายไปเลย" (เสี่ยง regression)                    |

> [!warning] เช็คด่วน — Citation regression
> รอบ 1 ผู้ใช้บ่น "ลิงก์ citation เสีย" แต่รอบ 2 บ่น "ไม่เห็น citation เลยเหมือนรอบแรก" — อาจเป็นฟีเจอร์ที่เคยมีแล้วหายไปหลัง refactor ต้องตรวจสอบว่าเป็นของจริงหรือผู้ใช้หาไม่เจอ

## 5. Trust Paradox

> [!important] ความย้อนแย้งที่เป็นแก่นของรอบ 2

```
Policy Impact สูงขึ้น (เชื่อในศักยภาพ)   ↑  3.56 → 3.87
        แต่
AI Trust ต่ำลง (ไม่เชื่อความแม่นข้อมูล)   ↓  3.56 → 3.23
```

ผู้ใช้รอบ 2 (สสจ. อาวุโส) **"อยากใช้จริงจนเริ่มตรวจสอบจริงจัง"** — ยิ่งเห็นคุณค่า ยิ่งเข้มงวดกับความถูกต้อง นี่เป็น **สัญญาณดี** (ผู้ใช้ลงลึก) ไม่ใช่สัญญาณถดถอย
